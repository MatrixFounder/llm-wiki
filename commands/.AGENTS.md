# commands/ — source of truth для slash-команд wiki-* проекта

Маленькие wrapper-файлы (3–6 строк), которые Claude Code исполняет как `/<name>`. Каждый указывает на workflow в `workflows/` или прямо описывает что делать.

## Шаблон

```markdown
Read and execute the workflow defined in `workflows/<workflow-name>.md`.

Follow all steps sequentially. Load required skills as specified in each step.

User's task context:
$ARGUMENTS
```

## Подключение к Claude Code

`.claude/commands/<name>.md` — per-command симлинк на `../../commands/<name>.md`. Создаётся:

```bash
bin/link-command.sh <command-name>
```

Старые legacy-команды (`.claude/commands/vdd*.md`, `start-feature.md`, и т. д.) — обычные файлы, не трогаем.
