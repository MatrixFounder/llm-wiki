Run via Bash:

```bash
wiki-alias $ARGUMENTS
```

Wrapper at `bin/wiki-alias` handles cd + venv activation; works from any
CWD when the repo's `bin/` is on `PATH`. See `skills/wiki-alias/SKILL.md`
for `--add`/`--remove`/`--list`, `--type`, and exit semantics.
