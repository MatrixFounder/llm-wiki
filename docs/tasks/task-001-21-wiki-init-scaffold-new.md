# Task 001-21: `wiki-init --scaffold-new` flow [LOGIC IMPLEMENTATION]

## Use Case Connection
- UC-01 (scaffold new vault)

## Task Goal
Implement the scaffold-new flow in `scripts/wiki_skills/wiki_init.py`: interactive `vault_id` prompt (validated against schema pattern), creates `<vault>/WIKI_SCHEMA.md` with v2.0 frontmatter, creates directory tree, opens repo via factory, and registers vault row.

## Changes Description

### New Files
- `templates/WIKI_SCHEMA.md.j2` — Jinja2-style placeholder template (use `string.Template` if Jinja2 not added to deps):
  ```yaml
  ---
  name: WIKI_SCHEMA (root)
  schema_version: 2.0
  vault_id: ${vault_id}
  description: ${description}
  language: ${language}
  layout: ${layout}
  ---

  # Wiki schema for $vault_id

  (auto-generated by wiki-init; edit as needed)
  ```
- `templates/CLAUDE.md.j2` — minimal `wiki:` block template.

### Changes in Existing Files

#### File: `scripts/wiki_skills/wiki_init.py`

**Function `scaffold_new(args) -> int`:**
- Interactive prompt (or use `args.vault_id` if `--vault-id` provided): collect `vault_id`, `language` (default `en`), `layout` (default `per-project`), `description`.
- Validate `vault_id` against pattern `^[a-z][a-z0-9-]{1,30}[a-z0-9]$` (or via schema); fail-fast with diagnostic.
- Determine vault_root (from `args.vault <path>` or `os.getcwd()`).
- Create directory tree: `<vault>/{_sources,_concepts,_entities,_raw,_raw/.locks,_raw/failed,00-Vault-Index,00-Vault-Index/log}` (R-05.2 + ADR-002 §A8 + I-3.3 step c.1).
- Render `WIKI_SCHEMA.md` from template → write to `<vault>/WIKI_SCHEMA.md`.
- Render `CLAUDE.md` from template → write to `<vault>/CLAUDE.md` (skip if exists, unless `--force`).
- Render initial `<vault>/00-Vault-Index/index.md`, `<vault>/00-Vault-Index/log/{YYYY-MM}.md`, `<vault>/00-Vault-Index/taxonomy.md` skeletons.
- Open repo via `make_repo({'vault_id': vault_id, ...})`.
- Construct `Vault(...)` dataclass; call `repo.register_vault(vault)`.
- Print JSON: `{"action": "scaffolded", "vault_id": ..., "db_path": ..., "vault_root": ...}`.
- Return 0.

**Function `_interactive_prompt(field: str, default: str, validator: Callable | None = None) -> str`:**
- Uses `input(...)`; respects `--non-interactive` arg by returning default immediately.

### Component Integration
- Updates E2E harness (task-001-11): `scaffold_new` should leave the vault in a state where `repo.get_vault(vault_id)` returns the row.
