# Task 001-26: `wiki-index-render` impl — `index_meta` VIEW + atomic write + auto-shard [LOGIC IMPLEMENTATION]

## Use Case Connection
- UC-05 (bulk migration step 7)
- All operator UX

## Task Goal
Replace `wiki-index-render` stub with real impl: query the `index_meta` VIEW (defined in SCHEMA-v2.sql) for the target vault, group rows by category (project or type), render Markdown, write atomically via tempfile + os.rename. Preserve custom-section blocks per ADR-002 §D8 (operator may add prose between machine-generated sections; `<!-- BEGIN-CUSTOM ... END-CUSTOM -->` markers are preserved across re-renders).

## Changes Description

### New Files
- `scripts/wiki_index/rendering.py`:
  - `_CUSTOM_BLOCK_RE = re.compile(r"<!--\s*BEGIN-CUSTOM:([a-z0-9-]+)\s*-->(.*?)<!--\s*END-CUSTOM:\1\s*-->", re.DOTALL)`.
  - `def extract_custom_sections(existing_md: str) -> dict[str, str]:` — finds blocks, returns `{name: content_including_markers}`.
  - `def render_index(repo: IndexRepository, vault_id: str, vault_root: Path, *, preserve_custom: dict[str, str] | None = None) -> str:`
    - Query `SELECT * FROM index_meta WHERE vault_id = ?`.
    - Group by `project`; emit:
      ```markdown
      # Index — <vault_id>

      <!-- AUTO-GENERATED by wiki-index-render. Custom sections marked
           with BEGIN-CUSTOM/END-CUSTOM are preserved. -->

      ## Project: <project>
      ### Summaries (<N>)
      - [[Summaries/.../body|<title>]] — <tldr>
      ### Concepts (<M>)
      ...
      ```
    - Inject preserved custom sections at the appropriate offsets.
    - Return the rendered string.
  - `def auto_shard(content: str, max_pages: int = 200) -> dict[str, str]:` — if `pages > max_pages`, split by project → `{'index.md': summary, 'index/<project>.md': details}`.
  - `def atomic_write(path: Path, content: str) -> None:` — write to `path.with_suffix('.tmp')` then `os.rename` (atomic on POSIX; safe on macOS APFS).
