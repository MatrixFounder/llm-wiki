# scripts/wiki_source/ — Source Adapters Module Memory

**Purpose**: Pluggable adapters that normalize different source kinds (manual
markdown, transcript via wiki-ingest workflow, light LLM summary) into
`SourceOutput` dataclasses that `wiki-index-upsert` consumes.

## Files (planned for Phase 3a)

- `adapter.py` — `SourceAdapter` ABC + dataclasses (`SourceItem`,
  `SourceOutput`). (task-001-06)
- `manual.py` — `wiki-source-manual` adapter: indexes existing markdown files
  produced by wiki-ingest. Sets `trust_level='high'`. Path-traversal guarded
  (R-26). (task-001-07 stub → task-001-24 impl)

## Out of Phase 3a (Phase 3b — wait for wiki-ingest v1.1)

- `transcript.py` — wraps `/generate-detailed-meeting-summary` workflow.
  R-06.3. Subprocess + JSON manifest consumption.
- `light.py` — single-call LLM summary for ad-hoc markdown chunks. R-24.

## Contract (R-15.3 trust_level)

- Manual adapter (operator-curated markdown): `trust_level='high'`.
- Transcript adapter (LLM-generated): `trust_level='medium'`.
- Light summary adapter (single LLM call): `trust_level='medium'`.
