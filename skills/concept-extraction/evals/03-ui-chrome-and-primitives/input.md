# Как собрать дашборд в Dune за вечер

Конспект туториала из документации Dune: от сырых таблиц до опубликованного дашборда, по шагам и с примерами запросов.

## Шаг 1. Сырые таблицы

Данные лежат в декодированных таблицах вроде `ethereum.transactions` и `dex.trades`. В каждой строке есть колонка `block_number` — порядковый номер блока, в который попала транзакция, и `block_time` — время этого блока; по ним режут выборку за нужный период. Долларовые цены подтягивают из `prices.usd`, там интересует колонка `prices_usd` — цена токена на минутной сетке.

Сделки соединяют с ценами через `LEFT JOIN` — это соединение, которое сохраняет все строки левой таблицы, даже если справа совпадения не нашлось. Пустые цены закрывают функцией `COALESCE(p.price, 0)`: она возвращает первый непустой аргумент из списка. Чтобы оставить по одной сделке на кошелёк в сутки, строки нумеруют оконной функцией `ROW_NUMBER()` и берут первую; дневные агрегаты считают обычным `GROUP BY`.

```sql
select date_trunc('day', t.block_time) as day,
       count(*) as trades,
       sum(coalesce(p.price, 0) * t.amount) as volume_usd
from dex.trades t
left join prices.usd p on p.contract_address = t.token_bought_address
group by 1
```

## Шаг 2. Параметры

Параметризованный запрос — это запрос, в текст которого подставляются значения-параметры: адрес контракта, тикер токена, границы интервала дат. Автор пишет запрос один раз, а читатель дашборда подставляет свои значения прямо на странице и получает ответ под свой кошелёк — без правки SQL и без десятка копий одного и того же запроса под каждый случай.

## Шаг 3. Оформление

Цвет серии задают hex-кодом цвета: 2172E5 для основной линии, FF6B6B для аномалий. При наведении мыши график показывает тултип — всплывающую подсказку со значением точки под курсором; лишние поля из неё лучше убрать, иначе она закрывает половину графика. Пока запрос считается, Dune рисует индикатор прогресса — полосу, по которой видно, что дашборд не завис, а честно ждёт. Между графиками ставят текстовый виджет с парой предложений контекста. У столбчатой диаграммы включают режим стекирования, когда нужно показать доли внутри целого, и выключают, когда сравнивают абсолютные величины.

## Шаг 4. Почему дашборд тормозит

Тяжёлый запрос по всей истории считается минутами, и каждый открывший дашборд запускает его заново. Лечится это материализованным представлением: результат тяжёлого запроса сохраняется на диске как таблица и пересчитывается по расписанию, а дашборд читает уже готовые строки. Агрегат, посчитанный раз в час, обходится дешевле, чем тот же агрегат, посчитанный на каждый просмотр.

## Шаг 5. Публикация

Дашборд публикуют кнопкой в правом верхнем углу; ссылка становится доступна всем, а сам дашборд попадает в поиск по площадке.
