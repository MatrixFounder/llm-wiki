# Протокол: производительность распознавания паспортов

## Ключевые решения

Паспорта — отдельный приоритетный поток, распознавание не дольше 5 секунд.

## Нефункциональные требования

- **Производительность**: паспорт ≤ 5 сек.

## Реестр рисков

- **Технический**: ≤ 5 сек на плохом скане может требовать GPU — рост стоимости железа.
