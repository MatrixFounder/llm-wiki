Schema Change Request (SCR) workflow. Edits to this file or `wiki-index-v2.sql`
without an accompanying SCR get reverted in review.

## Class A/B/C contract (ADR-002 §D8)

All tables/views in this DDL are **Class B** (mirrors of vault markdown,
rebuildable via `wiki-reindex --full`) EXCEPT:

- `vaults.registered_at` — **Class C strict** (approximated from earliest
  `log_events.event_ts` on reindex; only true DB-only value).
- `schema_meta` rows — Class C strict (no vault representation).
- `batch_runs.status`, `batch_runs.errors_json`, `batch_runs.finished_at` —
  Class C operational (cannot be reconstructed; forensic-only).
- `source_state.value` — Class C cache (recomputable but costly).

Any new column added must declare its class in the inline comment.

## Upsert contract (M-4 — CRITICAL)

`pages` and `entities` MUST be upserted via
`INSERT … ON CONFLICT(<composite>) DO UPDATE SET …`. **NEVER** use
`INSERT OR REPLACE` on these tables — it DELETE+INSERTs the row, generates a
new `pages.id`, breaks FTS5 rowid stability, and CASCADE-deletes
`page_entity_refs`. See `pages` table comment in this DDL.

## Pragmas

Set at connection time, not in DDL:
- `PRAGMA journal_mode = WAL;`
- `PRAGMA synchronous = NORMAL;`
- `PRAGMA foreign_keys = ON;` — REQUIRED (CASCADE behavior depends on it)
- `PRAGMA temp_store = MEMORY;`
- `PRAGMA mmap_size = 268435456;`

`PRAGMA user_version` is set inside the DDL (§13.2) so it survives a raw
`sqlite3 db < wiki-index-v2.sql` apply path. **Current = 7** (v3 TASK 005, v4 TASK 006,
v5 TASK 008, v6 TASK 032 event-graph edges, **v7 TASK 034** — four more inverse-closed
`ref_type` pairs `invalidated-by`/`activated-by`/`uses`/`owns` + inverses). Every bump is
additive CHECK-enum values only; the DB is Class-B, so migration = drop the `.db`/`-wal`/
`-shm` + `wiki-reindex --full` (SQLite cannot ALTER-relax a CHECK on a populated table).
