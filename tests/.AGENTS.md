# tests/ — Testing Module Memory

**Conventions**

- Fixture data: `tests/fixtures/<kind>/<name>.{yaml,md,txt}`
  - `tests/fixtures/configs/` — config YAML fixtures for `config_loader` tests.
  - `tests/fixtures/vaults/` — minimal markdown vault layouts (added by
    task-001-10).
  - `tests/fixtures/source_extract/` — TASK 003 v2 fixtures: a synthetic
    source-page markdown + a deterministic LLM-response JSON. Used by
    `test_wiki_extract_concepts_integration.py` to exercise the full
    extraction pipeline without making live Anthropic API calls.
- Test files: `test_<feature>.py` (matches `pytest.ini::python_files`).
- Pytest fixtures live in `conftest.py` at the relevant level (root for shared,
  subdir for scoped).
- Each test must have a clear failure message (`assert x, "why x must hold"`).
- E2E tests use `tmp_path` for filesystem isolation; DB tests use sqlite3 over
  tmp_path-backed file (NOT `:memory:` — WAL pragma requires file).

**Anti-patterns to reject in review**

- Tests that pass by side-effect ("function ran without exception"). Always
  assert observable behavior.
- Mocked SQLite — use real sqlite3 over tmp_path. SQLite is fast enough; mocks
  hide schema mismatches.
- Shared mutable state between tests (no module-level DBs).
- Magic skip markers without rationale.
- `unittest.mock.patch("scripts.wiki_skills._manifest_consumer.<symbol>")`
  when the bound name lives in `scripts.wiki_skills.wiki_extract_concepts.*`
  or `scripts.wiki_skills.wiki_enrich.*` via module-top import. Patch the
  **importer's binding**, not the source-of-truth module. Risk R-2 in
  `docs/PLAN.md`; regression-tested by
  `test_patch_target_lock_at_skill_module` in `test_wiki_extract_concepts.py`.
- Calling the real Anthropic API in tests. Always mock via
  `mock.patch("anthropic.Anthropic")` returning a `_MockResponse`-style object
  with `.content[0].text`. Live API in CI burns tokens + makes runs flaky.
  Live API smoke is the operator's manual step (TASK.md §7).

**Coverage target**: `pytest-cov` ≥ 90% on `scripts/wiki_index/` and
`scripts/wiki_source/`. Enforced in benchmark/CI task (task-001-33).
