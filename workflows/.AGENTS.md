# workflows/ — source of truth для wiki-* workflow

Сюда кладутся новые workflow-файлы проекта (например, `ingest-source.md` — meta-workflow из §15 docs/TASK.md).

## Подключение

В отличие от скиллов, workflows **не симлинкуются** в `.claude/`. Вызов идёт через wrapper-команду:

```markdown
# commands/ingest-source.md
Read and execute the workflow defined in `workflows/ingest-source.md`.

User's task context:
$ARGUMENTS
```

Эта команда симлинкуется в `.claude/commands/`, путь к workflow остаётся относительным от корня проекта.

Старые legacy-workflow в `.agent/workflows/` живут отдельно — их wrapper-команды (в `.claude/commands/*.md`) ссылаются на `.agent/workflows/X.md`.
